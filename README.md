# Argus

A simulated C2-style (command-and-control) operations dashboard — a map-first console
that fuses synthetic drone/sensor feeds, a ticking event log, and a rules-based
recommendation panel into one operator screen. Built as the sixth and final piece of a
small portfolio of mythology-named demo apps (Janus, Siren, Themis, Athena, and the
main app, Siegfried) built by Josh Rubio to show fullstack + UX work during a job
search.

Argus — the hundred-eyed giant of Greek myth — is the name for "total surveillance."
This dashboard is the demo that leans into that idea visually while staying, in every
substantive way, honest about what it actually is: **a portfolio piece with a fake
feed, not a real monitoring system.**

**Full real-vs-simulated breakdown: see `/docs` inside the running app.**

## What it is

A single full-bleed dashboard: a live map with moving UAV and sensor markers, a status
bar, a scrollable asset list, a ticking event feed (geofence drift, low battery, link
degradation, sensor faults, calibration drift, weather notices), and a recommendation
panel that ranks suggested operational actions with a visible, explainable rule behind
each one. It is inspired by the general shape of real situational-awareness and C2-style
operator interfaces — not a specific product, and not a real deployed system.

## What's real

- **The map** — rendered with [MapLibre GL JS](https://maplibre.org/) (free,
  open-source, no account/token) on
  [CARTO's free dark-matter basemap style](https://github.com/CartoDB/basemap-styles),
  built on OpenStreetMap data. Attribution is shown on the map per their terms.
- **The geography** — the area of operations is centered on the real coastline near
  Almeria, Spain (where this portfolio was built), chosen purely as a legible backdrop.
- **The login gate** — a real cookie-based session gate that genuinely restricts the
  dashboard route (see "What's simulated" for why it still isn't real auth).

## What's simulated

- **Every asset.** Five UAVs on simple circular patrol orbits and three fixed sensor
  posts — callsigns, positions, headings, battery, link quality, task state — are all
  produced in the browser by a small deterministic simulation
  (`lib/simulation.ts`). Nothing is fetched from a real drone, sensor, or feed.
- **The "live" feel.** There is no WebSocket server and no database. A client-side
  `setInterval` ticks the simulation roughly once a second and re-renders — the same
  lightweight approach the rest of this portfolio uses instead of standing up real
  infrastructure to serve fake data.
- **The event feed.** Geofence drift, low-battery recalls, link issues, sensor faults,
  calibration drift, and weather notices are generated by a seeded pseudo-random
  stream at low, tunable probabilities. They're deliberately framed as abstract
  operational/logistics events, never as anything resembling real targeting data.
- **The recommendation panel.** A deterministic **rules engine** (`lib/rules-engine.ts`),
  not an LLM call. A small set of if/then rules evaluate the current simulated state
  every tick and rank the results by severity, each with a rationale that cites the
  exact numbers behind it. A real model call (e.g. Groq) was deliberately skipped — a
  transparent rule is more honest than a model dressed up to reason over numbers that
  are already fake.
- **The login itself.** Any input, or none, signs you in. No password is checked, no
  account exists, and nothing is stored beyond a plain demo session cookie.

See `/docs` in the running app for the full breakdown, including known limitations of
the simulation.

## Visual identity

Benchmarked against real, publicly documented situational-awareness tooling before any
design token was chosen:

- **NASA Open MCT** ([github.com/nasa/openmct](https://github.com/nasa/openmct)) —
  open-source mission control framework: dense, hierarchical, telemetry-first panels.
- **Grafana's dark theme** — near-black panel backgrounds, small/tight corner radii, a
  single accent reserved for alerts, Inter + a monospace face for UI vs. data.
- **MarineTraffic's 2023 web redesign** — a map-first canvas with floating,
  de-clutterable side panels instead of a boxed dashboard grid.

Identity choices, distinct from the other four satellites in this portfolio
(Janus/amber, Siren/cyan, Themis/violet, Athena/phosphor-green):

- **Accent** — a warm signal red-orange, reserved for the accent and for critical
  status only (never decorative).
- **Type** — Inter (UI chrome) + Roboto Mono (telemetry, coordinates, IDs), the pairing
  real dashboard tooling (Grafana) actually ships.
- **Radius** — small (`0.4rem`): denser and sharper than Janus/Athena, short of
  Themis's zero-radius terminal look.
- **Density** — deliberately busy: multiple live panels, a ticking feed, moving map
  markers, per direction to lean into real density rather than minimalism here.

## Stack

- Next.js 16 (App Router, Turbopack, TypeScript, Cache Components + Partial Prefetching)
- Tailwind CSS v4, shadcn/ui-style components on `@base-ui/react`
- MapLibre GL JS + CARTO dark-matter basemap tiles
- A hand-rolled client-side simulation engine and rules-based recommendation engine
- Cookie-based demo auth (`proxy.ts` + a `use server` sign-in/out action), matching the
  rest of this portfolio

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The login gate accepts any input
(or none) — see `/docs` for why.

```bash
npm run build   # production build
npm run lint    # eslint
```
